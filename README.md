# arabic-pptx

بلوقن يجعل Claude ينشئ عروض بوربوينت عربية صحيحة الاتجاه، ويصلح العروض العربية التي خرجت باتجاه خاطئ.

## المشكلة التي يحلها

أدوات توليد العروض تكتب النص العربي بمحاذاة لليمين لكن باتجاه فقرة من اليسار لليمين. النتيجة: نقطة نهاية الجملة تظهر في أولها، والترقيم مثل 1.2 يظهر في الجهة الخطأ، والجداول معكوسة.

## المكونات

| المكون | الوظيفة |
|---|---|
| مهارة `arabic-pptx` | خطوات إنشاء العرض العربي: ترتيب الكتابة، عكس التخطيط، الخطوط، ثم الإصلاح والفحص |
| `scripts/rtl_fix.py` | يصلح أي ملف pptx: اتجاه الفقرات، المحاذاة، لغة النص، خط الحروف العربية، اتجاه الجداول، والقوالب الرئيسية |
| `references/ooxml-rtl.md` | مرجع الخصائص التي تضبط الاتجاه، وجدول الأعطال وحلولها |
| `references/shapes-and-diagrams.md` | الأشكال والمخططات وSmartArt في العرض العربي |

## الاستخدام

- اطلب: "سوي لي عرض بوربوينت بالعربي عن ..." وستعمل المهارة تلقائيا.
- لإصلاح ملف موجود: ارفع الملف واطلب "أصلح اتجاه هذا العرض".
- يدويا:

```bash
python3 skills/arabic-pptx/scripts/rtl_fix.py deck.pptx            # إصلاح في نفس الملف
python3 skills/arabic-pptx/scripts/rtl_fix.py deck.pptx --check    # فحص فقط
python3 skills/arabic-pptx/scripts/rtl_fix.py deck.pptx -o out.pptx --slides-only
```

## المتطلبات

Python 3 مع مكتبة lxml.
